# Decision records

Short notes on the structural choices in this project and why they were made.
One file per decision, numbered in the order they were taken. They are not
updated once written; if a decision is reversed, a later record supersedes it.

Format:

```
# NNNN. Short title

Date: YYYY-MM-DD
Status: accepted | superseded by NNNN

## Context

What made this a decision rather than an obvious default. What constraints
were in play.

## Decision

What was chosen, stated plainly.

## Consequences

What this makes easy, what it makes harder, and what has to be revisited if
the assumptions change.
```
